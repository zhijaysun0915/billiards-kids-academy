## 🆕 v3.0 重大更新亮點 (跳球、自由球點選、扎桿弧線)

### 1. 🦘 專業短跳桿（Jump Cue）與 3D 空中拋物線物理（Jump Shot）
- **真實世界撞球科學**：依循國際撞球賽事（WPA）標準規則，**嚴禁從球底往上挑球（違規鏟球 Scoop Foul）**！
- **石板反彈力學模型**：真正的跳球是使用短跳桿以 35° / 45° / 55° 高俯角由上往下將母球重重壓縮撞擊石板（Slate Bed），母球受壓後因極限彈性反作用力向上騰空反彈飛躍！
- **空中跨越障礙球判定（Airborne Obstacle Clearance）**：當母球在空中飛行高度超過障礙球時，完全免除球體碰撞判定，帥氣凌空飛越障礙球！
- **3D 騰空透視與動態軟陰影**：母球飛起時，球體沿 Z 軸動態向上偏移並以透視比例放大，球桌呢布上同步投射柔和動態陰影與騰空高度標籤（`🦘 98px`）。
- **跳球瞄準科學輔助線**：實時計算繪製拋物線軌跡、最高空頂點（Apex）、落地點光圈（`🎯 落地點`）、障礙球跨越成功檢測（`✅ 越過 / ⚠️ 太低將撞到`）。

### 2. ✋ 自由球（Ball-in-Hand）直覺點選與擺放
- **隨手一按直接放球**：手機或平板玩家不用再辛苦從微小的白球邊緣拖曳！自由球開啟時，**直接在球桌任意空曠處「輕點一下」**，白球立刻飛到該處！
- **即時合法性預覽**：滑鼠或手指在球桌上滑動時，即時顯示綠色（合法可放）與紅色（與其他球重疊或靠邊）十字準心與光圈指引。
- **快選捷徑列**：支援 `[開球線]`、`[球桌中央]`、`[✅ 確認擺球]` 一鍵到位按鈕。

### 3. 🌀 扎桿弧線球（Massé Shot）
- 將球桿立起 75 度重擊白球側翼，利用強烈側旋產生的陀螺進動（Gyroscopic Precession）與呢布摩擦力，讓白球在桌上劃出優美的 C 型弧線，神奇繞過障礙球！

- **第 3 關｜推桿 (高桿) vs 拉桿 (低桿) 的魔法**：體驗打擊母球下方產生逆旋轉（拉桿／倒退嚕），進球同時避免母球洗袋犯規。
- **第 4 關｜認識「一顆星」鏡面反射解球**：當直線路徑被障礙球擋住時，利用球桌邊緣的「💎 鑽石刻度」與「入射角 ＝ 反射角」原理打一顆星解球。
- **第 5 關｜「下塞（左塞／右塞）」顆星大轉彎**：體驗側旋球（English）撞擊顆星時的齒輪咬合效應，看母球如何改變反射角度繞過障礙進球。
- **第 6 關｜做球走位雙球清台 (1號 ➔ 9號)**：控制母球撞擊第一顆球後的走位路線，連續將 1 號球與 9 號球打進袋口。
- **第 7 關｜🦘 神奇跳球 (Jump Shot) 飛越障礙球！**：使用短跳桿配合 45 度俯角，將白球向下重壓石板彈起，凌空躍過 8 號黑球推進 7 號球。

## 🎮 操作方式

1. **瞄準方向**：在球桌上移動滑鼠點擊或按住拖曳，即可旋轉球桿對準目標（也可使用右側 `↺ 微調左轉 0.5°` / `↻ 微調右轉 0.5°` 按鈕精準微調）。
2. **球桿切換**：可選擇 **標準打桿 (Standard)**、**🦘 專業短跳桿 (Jump Shot，支援 35°/45°/55° 俯角)** 或 **🌀 扎桿弧線 (Massé)**。
3. **調整下塞打點**：點擊右側「母球打點與下塞控制」的白球圓盤，或點選預設桿法按鈕。
4. **調整力道與出桿**：拉動「出桿力道」滑桿，點擊 **「🚀 出桿擊球！」** 按鈕或直接按鍵盤 **空白鍵 (`Space`)** 出桿。
5. **自由球擺放**：在自由球模式下，直接在球桌任意空曠處**點擊一下**即可立即擺放白球，亦可直接拖曳。
